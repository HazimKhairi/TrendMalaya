Here's a detailed technical and design review focused on the elements you asked about:

Design
The site uses a Wix-based layout with a clean, Apple-inspired aesthetic. It relies on generous whitespace, a mostly monochrome palette (black text on white), and pastel-colored service cards (light blue, cream, black). The typography stack is solid — it uses Poppins (semibold), Helvetica, and "MadeFor Display ExtraBold" for the marquee. The hero image is a high-res angled MacBook keyboard that works well as a visual anchor. The total page height is about 4994px across 7 sections, 10 images, 25 SVGs, and 3 iframes.
One design issue: the header/navbar uses position: relative, meaning it scrolls away with the page and is not sticky. Once you scroll past the hero, there's no navigation visible — users have to scroll all the way back to the top. For a service-oriented site, a sticky header (or at least a floating back-to-top button) is expected.
The heading hierarchy is properly structured: one H1 ("No. 1 Mac Specialist MY"), followed by H2s for major sections ("Our Services", "Bringing Life Back to Your Beloved Gadgets"), H3s for sub-sections ("MacBook repair", "iMac repair", etc.), and H4s for lower sections. This is good for SEO and accessibility.

Animations
The site uses Wix's built-in motion system. There are 13 elements tagged with data-motion-enter, all currently in the "done" state — meaning they have scroll-triggered entrance animations that have already fired. These animate in the hero text ("No. 1 Mac Specialist MY"), the sub-headline, the "Start Repair" button, the Google badge, the service cards, and the gadgets showcase section. They appear to be simple fade-in/slide-up entrance animations.
The marquee is the most notable animated element. It uses a CSS keyframe animation called "OEe22F" with a 15.86s duration, running infinitely in a linear loop. It displays "Installment available. Up to 5 years warranty." in a massive 86px font using the MadeFor Display ExtraBold typeface, scrolling continuously from right to left. The text color is a dark gray (#404040). The issue is that the container has overflow: visible, and the font is so large (86px) that the text visibly clips at the viewport edges — you can see it cut off mid-word on both sides of the screen. This looks unfinished. It would benefit from a more controlled overflow behavior or a slightly smaller font size.
Beyond those entrance animations and the marquee, there are no complex animations, parallax effects, or scroll-driven transitions. No GSAP or third-party animation libraries are loaded. The experience feels quite static once the initial load-in animations complete.

CTA Buttons
"Start Repair" (Primary CTA): This is a pill-shaped button (border-radius: 50px) with a blue background (rgba(0, 138, 252, 0.93)) and white text at 18px. It includes a right-arrow chevron SVG icon (also white). The button is 186×51px with a 0.2s transition. However, there's a critical issue: the button links to the homepage itself (the same page the user is already on). It doesn't navigate to a repair intake form, a contact page, or a WhatsApp chat. This completely defeats its purpose as a call-to-action. On hover, the button does not show any visible state change — no color shift, no scale, no shadow — which makes it feel unresponsive.
"Get a free consultation" (Secondary CTAs): These appear twice on the page (in the gadgets section and the "Why YKL" section). They're text-style links (19px, dark gray text on transparent background) with an arrow icon. They correctly link to WhatsApp (wa.me/60374959092) and open in a new tab — good UX for a Malaysian audience.
Value Proposition Card Arrows (the "Next" buttons): The four cards ("Up to 5 years warranty", "Pay over time", "Free pick up", "Same-day service") each have dark circular arrow buttons at the bottom right. The icon links on each card correctly go to relevant service pages (water damage repair, battery replacement, screen repair, screen replacement). However, the "Next" buttons themselves have no href — they appear to be non-functional buttons that don't navigate anywhere. The visual design suggests they should do something, creating a confusing interaction pattern.
Google 5-Star Badge: This is an SVG/vector image next to the "Start Repair" button. It links to the Google Knowledge Graph page for the business — good for social proof.
Waze Buttons (Footer): Green pill-shaped buttons with the Waze emoji, linking to the Waze app for each location. These are well-designed and contextually appropriate.
WhatsApp Contact Buttons (Footer): Green buttons linking to wa.me and wasap.my for each branch. Functional and appropriate for the market.

Iframes & Embedded Content
The site has 3 iframes:
1. Google Reviews (1361×335px): This loads a custom HTML file hosted on Wix's file server (filesusr.com), which renders a Trustindex-powered Google Reviews carousel. It shows recent 5-star reviews (January–February 2026) with reviewer names, dates, photos, and a "Verified by Trustindex" badge. It has left/right navigation arrows for browsing reviews. This is a well-chosen widget that adds credibility. The reviews appear genuine and recent.
2. TikTok Feed (1262×626px): Also loaded via Wix's custom HTML hosting. It displays a TikTok-style grid/carousel showing the business's repair videos, with the account profile (159 posts, 12K followers), a "Follow" button, and left/right navigation. The videos show real repair work, which is excellent for trust-building. However, this iframe is large and likely adds significant load time.
3. Hidden/Empty Iframe (0×0px): A zero-size invisible iframe — likely a Wix system iframe for analytics, tracking, or internal functionality. Not visible to users.
Both the Google Reviews and TikTok iframes are implemented as Wix Custom HTML elements, meaning the content is loaded from the site's own file hosting rather than directly from Google/TikTok APIs. This approach gives more design control but means the embedded content is managed separately.

WhatsApp Widget (Smartarget)
There's a floating WhatsApp chat button in the bottom-right corner, powered by Smartarget (a Wix-compatible third-party app). It displays a green WhatsApp icon and includes "by Smartarget" branding text below it. This is functional and expected for Malaysian businesses, but the third-party branding looks slightly unprofessional. If possible, consider using a paid tier of the widget or a self-hosted implementation to remove the branding.

Navigation
The nav has 4 main items: Home, Services (with dropdown), Contact, and Blog, plus a shopping cart. The Services item has a dropdown with sub-items: "MacBook/iMac Repair and Upgrade", "iPad Repair", and "Smartphone Repair (All brands)." These dropdown items are hidden by default and revealed on interaction. Notably, iPad Repair appears in the dropdown but is not mentioned anywhere else on the homepage — there's no iPad service card on the page, which creates an inconsistency.

Key Issues Summary
The "Start Repair" button linking to the homepage is the most critical issue — it's the primary CTA and it goes nowhere useful. The non-sticky navbar means users lose access to navigation once they scroll. The marquee text overflow looks unpolished. The "Next" buttons on value proposition cards are non-functional. The button hover states are missing, making the site feel less interactive. And the Smartarget branding on the WhatsApp widget could be cleaned up for a more professional finish.
